Why this one goes deeper

The other cases stop at district because a published statistic is collected on particular administrative units, and drawing a 2011 figure on 2019 outlines would misstate which places were measured. A live API has no vintage — it answers for a coordinate, now — so every level of the current bundle can be filled honestly, including all 5,950 sub-districts.
